02 / ACTUATOR INTEGRATION

Add relay-based appliance control

Connect a single-channel relay module to the ESP32 as the low-voltage control interface for the appliance. In the provided plan, GPIO 26 drives the relay input.

CONTROLESP32 GPIO 26
INPUTRelay IN
CONTACTSRelay contacts
SWITCHED LOAD230 V bulb
CONTROL SIDE

ESP32 signal

The ESP32 output changes the relay-module input according to the selected mode and calculated bulb state.

LOAD SIDE

Relay contacts

Properly rated relay contacts switch the appliance circuit; the relay rating must suit the actual load.

Mains safety: 230 V mains wiring can cause fatal electric shock or fire. Disconnect power before wiring. Use a correctly rated relay in an insulated enclosure, keep mains wiring isolated from low-voltage electronics, and have the mains side wired or inspected by a qualified person.

05 / SENSOR-DRIVEN CONTROL

AUTO mode with an LDR threshold

When mode is AUTO, the ESP32 compares the LDR reading against the configured threshold. For this project requirement, values above 3000 switch the bulb ON; values at or below 3000 switch it OFF.

LDR > 3000

BULB ON

Light reading exceeds the configured threshold.

LDR ≤ 3000

BULB OFF

Light reading is at or below the threshold.

Configured threshold: ldrThreshold = 3000. The active threshold is stored in Firebase and reported in current status so the dashboard can show the decision boundary being used.

READLDR value
COMPAREThreshold 3000
SWITCHSet relay state
REPORTUpdate Firebase

MANUAL mode follows the user's dashboard request. AUTO mode ignores the manual request while active and determines the output from the LDR comparison. Calibrate the threshold against readings from the actual sensor and environment.

11 / ELECTRICAL SAFETY

Relay and mains precautions

230 V mains can cause fatal electric shock or fire. Disconnect mains power before wiring. Use a relay rated for the load in an insulated enclosure, maintain isolation between mains and low-voltage electronics, and have mains wiring installed or inspected by a qualified person. Do not handle exposed live wiring during testing.

The ESP32 GPIO is a low-voltage control signal only. Do not connect a mains conductor directly to an ESP32 pin.
